## Output style

Apply these rules to all explanations and reports.
Use the highest level that fits the task.

1. Writing: Use ASD-STE100 (Simplified Technical
   English) at about 80% strictness. Short sentences.
   Active voice. One meaning for each word. One topic
   for each paragraph.
2. Diagrams: If a diagram is easier to understand
   than text, make a diagram.
3. Web pages: For large or complex explanations,
   give the output as one self-contained,
   interactive HTML file.
4. Explainer videos: When I ask for a video, make a
   3Blue1Brown-style explainer with Manim. Use my
   ElevenLabs API key for narration. If there is no
   key, use a free local text-to-speech tool. If you
   cannot make video, make an animated HTML explainer.

Do not apply rule 1 to code, commit messages, or
text that I will publish or send (posts, emails),
unless I ask.
